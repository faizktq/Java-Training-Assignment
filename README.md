**Submission Date:** 19/12/2025  
**Topic:** Automation Testing: Selenium with Java  

## Description
This repository contains the solutions for Assignment 1, covering the following topics:

1.  **BasicMathOperations.java**: Basic arithmetic, square, cube, and absolute value calculations.
2.  **ArrayOperations.java**: Insertion, deletion, search (linear/binary), sorting, and min/max in arrays.
3.  **MatrixOperations.java**: Matrix addition, subtraction, multiplication, transpose, and identity checks.
4.  **StringOperations.java**: String vs StringBuffer vs StringBuilder and various string methods.
5.  **BankManagement.java**: A console-based banking system with exception handling.
